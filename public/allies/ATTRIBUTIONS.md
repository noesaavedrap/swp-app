# Ally logo sources

The ally SVGs are local brand-style assets used for the SWP partner showcase:

- ENTEL: visual reference from https://www.entel.pe/
- DHL: visual reference from the official DHL brand presentation at https://www.dhl.com/
- On Solutions: custom local wordmark based on the supplied GitHub avatar reference.
- Aliclick: custom local wordmark based on the supplied company name.

These assets are displayed to identify proposed or illustrative SWP allies. Confirm each company's brand guidelines and obtain permission before using the logos in a commercial partnership claim.
